# Welcome

!!! info "Thank you for visiting "

## Help

If you're having problems running the program, please create a **[help request]**.

Go to our [Troubleshoot](troubleshoot.md) page to see how to gather information from your workstation.

## Feedback and improvements

If you have a new use-case for the program, please create a **[feature request]**.

To ask a question or add a suggestion about the website, create a **[site request]**.

## Bugs

If you're encountering incorrect behavior, please create a **[bug report]**.

If you want to fix a bug, thank you for contributing
&nbsp;:lucide-heart-handshake:{ .lg .qtpy }&nbsp;
Continue reading below.

## Developing

If you want to tinker with the code or contribute to the project, go to our [Environment](eng/intro/environment.md) page to setup your workstation.

- To learn how this project **tests and analyzes** its code, go to our [Python](eng/intro/python.md#testing-code) page.
- To learn about the **code design and structure**, go to our [Design Doc] pages.
- If you're new to **debugging or writing tests**, go to our [How-to code](eng/howto/code.md) page.

If want to share your changes, thank you for your effort
&nbsp;:lucide-heart-handshake:{ .lg .qtpy }&nbsp;
Please go to our [How-to engage](eng/howto/engage.md) page for next steps.
